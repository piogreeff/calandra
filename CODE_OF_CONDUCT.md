# Code of Conduct

This project adopts the [Contributor Covenant](https://www.contributor-covenant.org/version/2/1/code_of_conduct/), version 2.1.

In short: be respectful, assume good faith, and keep discussion focused on the work. Harassment, discrimination, and personal attacks are not tolerated.

Report conduct concerns privately to the maintainer via the contact listed on [github.com/piogreeff](https://github.com/piogreeff). Reports will be handled confidentially.
